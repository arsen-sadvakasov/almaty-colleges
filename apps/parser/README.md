# Парсер данных колледжей

Скрипт предназначен для автоматизированного сбора (парсинга) информации с официальных сайтов колледжей Алматинской области. 

## Стек
- `axios` — для HTTP-запросов.
- `cheerio` — для парсинга HTML и извлечения нужных данных (DOM-манипуляции).
- `ts-node` — для запуска TypeScript напрямую.

## Запуск

Установите зависимости (если еще не установлены):
```bash
npm install
```

Запустите скрипт парсера:
```bash
npx ts-node index.ts
```

Скрипт обойдет заданные URL (массив `TARGET_URLS`), соберет данные о специальностях, описании и инфраструктуре колледжа, и сохранит результат в `data/parsed_colleges.json`.

## Периодическое обновление (Cron)

Для актуализации данных (например, каждую неделю в воскресенье ночью) на сервере (например, Ubuntu) рекомендуется использовать `cron`.

Откройте планировщик cron:
```bash
crontab -e
```

Добавьте следующую строку, чтобы парсер запускался каждое воскресенье в 03:00 ночи:
```bash
0 3 * * 0 cd /путь/к/проекту/apps/parser && npx ts-node index.ts >> cron.log 2>&1
```

Собранные данные будут автоматически сохраняться в JSON. В дальнейшем этот парсер можно интегрировать с базой данных (ЭТАП 15), чтобы при парсинге данные записывались напрямую в PostgreSQL или MongoDB через Prisma ORM.
